# Changelog

Все важные изменения в проекте Speech Manager будут документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.1.7] - 2026-01-26

### Исправлено
- 🐛 **Иконка на панели задач**: Окно приложения теперь отображается на панели задач Windows (убран флаг Qt.Tool)

## [1.1.6] - 2026-01-26

### Исправлено
- 🐛 **Зависания интерфейса**: Устранены периодические подвисания приложения из-за обновления UI не из главного потока Qt
- 🔧 **QMetaObject.invokeMethod**: Заменены вызовы на сигналы Qt — обновление статуса, окна и громкости теперь выполняется в главном потоке

### Изменено
- **Поток распознавания**: Обработчик горячей клавиши запускает распознавание в отдельном потоке, не блокируя поток библиотеки keyboard
- **Сигналы MainWindow**: Добавлены `status_update_requested`, `show_window_requested`, `show_volume_bar_requested`, `volume_update_requested` для потокобезопасного обновления UI
- **.gitignore**: Добавлены `.vscode/` и `.atom8n/`

## [1.1.5] - 2026-01-24

### Исправлено
- 🐛 **Буфер обмена**: Исправлена проблема, когда текст попадал в буфер обмена даже при выключенной настройке "Буфер обмена"
- 🔧 **Восстановление буфера**: При выключенной настройке "Буфер обмена" и включенной "Вставка в курсор", предыдущее содержимое буфера обмена теперь восстанавливается после вставки

### Технические изменения
- Добавлена логика сохранения и восстановления предыдущего содержимого буфера обмена
- Улучшена обработка случая, когда `output_clipboard` выключен, но `output_text_cursor` включен

## [1.1.4] - 2026-01-24

### Добавлено
- 🪟 **Адаптивная высота окна**: Окно теперь автоматически подстраивает высоту под количество видимых сообщений
- 📏 **Умные отступы**: Сверху и снизу окна остаются отступы, равные половине высоты одного инпута

### Изменено
- Улучшена автоматическая подстройка размера окна: теперь подстраиваются и ширина, и высота одновременно
- Добавлен метод `adjust_window_height()` для расчета оптимальной высоты на основе видимых элементов
- Добавлен метод `adjust_window_size()` для одновременной подстройки ширины и высоты

## [1.1.3] - 2026-01-24

### Добавлено
- 📁 **Портативная конфигурация**: Приложение теперь ищет и создает `config.json` в папке с .exe файлом, а не в папке исходников
- 📋 **Автоматическое создание конфига**: При первом запуске, если `config.json` не найден, приложение автоматически создает его с дефолтными значениями
- 📝 **Копирование config.json.example**: При сборке `config.json.example` автоматически копируется в папку `dist` для пользователей

### Изменено
- 🔧 **Логика загрузки конфига**: Теперь конфиг ищется в папке с исполняемым файлом (для .exe) или в текущей рабочей директории (для Python скрипта)
- 📊 **Лог-файл**: `speech_manager.log` теперь также создается в папке с .exe файлом
- 🪟 **Адаптивная ширина окна**: Ширина окна автоматически подстраивается под длину самого длинного текста в сообщениях

### Исправлено
- 🐛 Исправлена проблема, когда конфиг искался в неправильной директории при запуске из .exe

## [1.1.2] - 2026-01-24

### Добавлено
- ⏹️ **Остановка записи горячей клавишей**: Возможность остановить текущую запись повторным нажатием той же горячей клавиши
- ⚙️ **Настройка остановки записи**: Галочка в настройках для включения/выключения функции остановки записи горячей клавишей
- 📝 **Максимальная длина сообщений**: Настройка максимальной длины текста, отображаемого в сообщениях (по умолчанию 500 символов)

### Изменено
- Улучшена обработка записи: при остановке горячей клавишей уже записанное аудио обрабатывается и отправляется на распознавание
- Добавлен флаг `enable_hotkey_stop_recording` в конфигурацию (по умолчанию включен)

## [1.1.1] - 2026-01-19

### Исправлено
- 🔧 **Динамическое определение языка**: Статусные сообщения теперь обновляются в реальном времени при изменении раскладки клавиатуры во время прослушивания или обработки
- 🔧 Улучшена функция `update_status()` для автоматического определения языка при каждом обновлении

## [1.1.0] - 2026-01-19

### Добавлено
- 🌍 **Локализация интерфейса** с поддержкой 6 языков (русский, английский, украинский, немецкий, французский, испанский)
- ⌨️ **Автоматическое определение языка** по текущей раскладке клавиатуры Windows
- ⚙️ **Выбор языка интерфейса** в настройках приложения
- 📝 **Модуль i18n** для управления переводами статусных сообщений
- 📖 **Документация по локализации** (LOCALIZATION.md)

### Изменено
- Статусные сообщения (Ready, Listening, Recognizing, Done и т.д.) теперь автоматически отображаются на языке текущей раскладки клавиатуры
- Добавлена функция `get_keyboard_language_code()` в модуле `state` для определения текущего языка ввода

## [1.0.0] - 2026-01-19

### Добавлено
- 🎤 **Распознавание речи** через Google Speech Recognition API
- 🔥 **Горячая клавиша** для активации (Ctrl+Shift+Win+F5, настраивается)
- 🖥️ **Системный трей** с иконкой для фоновой работы
- ⚙️ **Окно настроек** с полным контролем параметров:
  - Выбор микрофона
  - Настройка горячих клавиш
  - Прозрачность окна
  - Размер шрифта
  - Автоматическое скрытие
  - Количество отображаемых сообщений
  - Режимы вывода (UI/буфер обмена/текстовый курсор)
- 📊 **Визуальная обратная связь**:
  - Цветовые индикаторы статуса (прослушивание/обработка/успех/ошибка)
  - Визуализатор громкости голоса
  - Таймер длительности записи
- 🎯 **Множественные режимы вывода**:
  - Отображение в UI окне
  - Копирование в буфер обмена
  - Вставка в активное текстовое поле
- 🔧 **Конфигурация**:
  - Файл `config.json` для сохранения настроек
  - Валидация настроек с помощью JSON Schema
  - Автоматическое создание конфига при первом запуске
- 📝 **Логирование**:
  - Централизованная система логов
  - Детальная информация о времени обработки
  - Ротация логов для экономии места
- 🧵 **Многопоточность**:
  - Менеджер потоков для безопасной работы
  - Потокобезопасное взаимодействие с Qt UI
- 🎨 **UI/UX улучшения**:
  - Современный интерфейс
  - Плавные переходы между статусами
  - Автоматическое скрытие после распознавания
  - Кастомизируемая прозрачность
- 📦 **Сборка .exe**:
  - PyInstaller спецификация (`build_exe.spec`)
  - Автоматический скрипт сборки (`build.bat`)
  - Детальная документация по сборке (`BUILD.md`)
  - Оптимизированный размер (~89 MB)
  - Все зависимости включены

### Технические детали
- **Платформа**: Windows 10/11
- **Python**: 3.11+
- **Основные зависимости**:
  - PyQt5 для GUI
  - SpeechRecognition для распознавания речи
  - sounddevice + numpy для работы с аудио
  - pywin32 для интеграции с Windows API
  - keyboard для обработки горячих клавиш
  - tenacity для retry механизма API вызовов

### Производительность
- ⚡ Оптимизированное время отклика
- 🎯 Детальное логирование времени каждого этапа:
  - Время прослушивания
  - Время API запроса
  - Время обработки текста
- 🔄 Retry механизм для Google API с экспоненциальным backoff

### Документация
- README.md с инструкциями по установке и использованию
- BUILD.md с подробной информацией о сборке .exe
- Комментарии и docstrings в коде
- Type hints для всех функций
